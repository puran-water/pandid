# Fixed-scale operating-sheet caption clearance

Operating assemblies reserve the full measured inscription, including multiline
DN/class and fluid descriptions. Connected assemblies influence packing order,
and boundary rails follow their connected assembly order. Type size, sheet size,
canonical identities and the final native clearance gates remain unchanged.

An explicitly unminted, continuous uniform header may share one inscription
through junctions and inline valves. Equipment, changed properties, disconnected
runs and claimed line identities retain independent inscriptions. Alternative
description line breaks preserve all words and the identity and DN/class rows.

Caption repair reserves the actual stroked symbol/descriptor envelope and the
narrow corridor occupied by a leader. It can move an automatic interior pipe
track, while preserving nozzle directions, arrow leads, manual paths, body
clearance, parallel spacing and crossing clearance. The renderer supplies its
measured paper band; overflow repair never assumes a zero-coordinate origin.

Instrument placement uses frozen nominal equipment-tag reservations. Route-based
tag placements cannot make a fixed instrument tap chase a moving caption.
Capacity failures preserve diagnostic geometry before atomic state restoration.

Qualification against the preceding 505a101 pin: the checked drafting, composition,
caption, portable-delivery, crossing and native-clearance suites have no regressed
failure node IDs (baseline 305 passing tests; candidate 327, including new tests).
The instrument and routing suites also have no regressed node IDs (207 passing
tests at both revisions). These are bounded suite comparisons, not a claim that
every test in the fork or every drawing is qualified. Publication still requires
the actual native, physical and drafting checks for every rendered sheet.
