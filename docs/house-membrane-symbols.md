# Construction-specific symbol candidates

Original artwork in `pandid/render/house_artwork.py` distinguishes open concrete basins, flat-bottom atmospheric plastic tanks, cartridge housings, immersion heaters, spring-loaded relief valves and three-port side-entry membrane vessels. No symbol supplies a rating, material specification, element count or approval. Template review remains required; this is not a claim of complete ISO 10628 or ISA 5.1 qualification.
